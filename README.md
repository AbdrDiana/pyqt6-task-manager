# Task Manager — приложение на PyQt6

## 1. Описание проекта

**Task Manager** — это настольное приложение для создания и управления задачами, разработанное на языке Python с использованием библиотеки PyQt6.

Программа позволяет пользователю создавать задачи, указывать их описание, выбирать приоритет и дополнительные параметры. Созданные задачи отображаются непосредственно в графическом интерфейсе.

Проект выполнен в рамках домашнего задания **«PyQt6 — Task Manager»**.

Основная цель работы — научиться создавать графические интерфейсы с использованием Qt Widgets, правильно применять компоновщики (layouts), работать с сигналами и обработчиками событий.

## 2. Функциональные возможности

### Основные функции

**Создание задачи**

Пользователь может ввести название задачи, добавить описание, выбрать приоритет и дополнительные параметры, а затем нажать кнопку Create task.

**Название задачи**

Для ввода названия используется QLineEdit. Это однострочное текстовое поле.

Название обязательно для заполнения. Если пользователь попытается создать задачу без названия, приложение покажет предупреждение.

**Описание задачи**

Для описания используется QTextEdit, позволяющий вводить текст в несколько строк.

Описание не является обязательным.

**Выбор приоритета**

Пользователь может выбрать один из трёх приоритетов:

- Low — низкий;
- Medium — средний;
- High — высокий.

Для выбора используются QRadioButton, объединённые в QButtonGroup.

По умолчанию выбран приоритет Medium.

**Дополнительные настройки**

В приложении предусмотрены два независимых параметра:

- Important — отметить задачу как важную.
- Send notification — сохранить признак необходимости уведомления.

Для настройки параметров используются QCheckBox.

Важно: Send notification сохраняется как свойство задачи, но фактическая отправка системных уведомлений не реализована.

**Отображение результата**

После нажатия Create task информация собирается в словарь Python, добавляется в список созданных задач и отображается в QListWidget.

Дополнительно информация о созданной задаче выводится в консоль.

### Дополнительные функции

Помимо обязательных требований, в приложении реализованы следующие возможности.

**Очистка формы (Clear)**

Кнопка Clear удаляет введённые название и описание, снимает галочки дополнительных настроек и устанавливает приоритет Medium.

**Отображение статуса**

В нижней части окна отображается текущий статус:

- Status: Ready — приложение готово к работе;
- Status: Task created — задача создана;
- Status: Last task deleted — последняя задача удалена.

**Счётчик задач**

Над списком отображается количество созданных задач в формате:

`Created tasks: 3`

При создании и удалении задач счётчик автоматически обновляется.

**Удаление последней задачи**

Кнопка Delete last task удаляет последнюю добавленную задачу из списка Python.

После удаления обновляются список задач и счётчик.

Если задач нет, появляется информационное сообщение.

**Фильтрация по приоритету**

Для фильтрации используется QComboBox со следующими вариантами:

- All — показать все задачи;
- Low — только задачи с низким приоритетом;
- Medium — только задачи со средним приоритетом;
- High — только задачи с высоким приоритетом.

При переключении фильтра отображаемый список обновляется.

**Хранение задач**

Задачи хранятся в списке Python `self.tasks`.

Каждая задача представлена словарём, содержащим название, описание, приоритет и значения дополнительных настроек.

Данные существуют только во время работы приложения. После закрытия программы они не сохраняются.

## 6. Установка приложения

Для запуска необходим Python версии 3.10 или новее.

### 6.1. Получение проекта

Скачайте архив репозитория с GitHub и распакуйте его либо клонируйте репозиторий с помощью Git.

Перейдите в папку проекта.

### 6.2. Создание виртуального окружения

Для macOS или Linux:

```bash
python3 -m venv .venv
```

Для Windows:

```bash
python -m venv .venv
```

### 6.3. Активация окружения

На macOS или Linux:

```bash
source .venv/bin/activate
```

На Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

### 6.4. Установка зависимостей

Выполните:

```bash
python -m pip install -r requirements.txt
```

После выполнения команды библиотека PyQt6 и необходимые компоненты будут установлены в виртуальное окружение.

## 7. Запуск приложения

Находясь в папке проекта с активированным виртуальным окружением, выполните:

```bash
python main.py
```

После запуска откроется отдельное окно с названием Task Manager.

## 8. Инструкция пользователя

### Создание задачи

1. Запустите приложение.
2. Введите название в поле Task.
3. Напишите описание в поле Description.
4. Выберите приоритет Low, Medium или High.
5. При необходимости включите Important и Send notification.
6. Нажмите Create task.

Созданная задача появится в разделе Tasks.

### Очистка формы

Для очистки полей нажмите Clear.

### Просмотр задач

Все созданные задачи отображаются в разделе Tasks.

Для каждой задачи показываются:

- Название.
- Описание.
- Приоритет.
- Значение Important.
- Значение Send notification.

### Фильтрация

Для просмотра задач с определённым приоритетом выберите нужное значение в выпадающем списке Filter.

Чтобы снова увидеть все задачи, выберите All.

### Удаление

Нажмите Delete last task, чтобы удалить последнюю добавленную задачу.

Удаление выполняется из общего списка независимо от выбранного фильтра.

## 9. Особенности реализации

### Главное окно

Класс `TaskManagerWindow` наследуется от QMainWindow.

Для размещения интерфейса создаётся центральный QWidget, который устанавливается с помощью `setCentralWidget()`.

### Компоновщики

Основной компоновщик — QVBoxLayout. Он отвечает за вертикальное расположение элементов.

QHBoxLayout используется для горизонтального размещения радиокнопок, дополнительных настроек, кнопок управления и элементов фильтрации.

Все компоновщики вложены в основной layout.

Метод `setGeometry()` не используется для построения всего интерфейса.

### Сигналы и обработчики

Кнопки подключаются к обработчикам через механизм сигналов и слотов PyQt6.

Пример:

```python
self.create_button.clicked.connect(self.create_task)
```

После нажатия кнопки вызывается метод `create_task()`.

### Получение информации из формы

- `text()` получает название из QLineEdit.
- `toPlainText()` получает описание из QTextEdit.
- `isChecked()` проверяет выбранный приоритет и состояние галочек.

### Создание и хранение задач

Данные объединяются в словарь Python и добавляются в список с помощью `append()`.

Для удаления последней задачи применяется `pop()`.

После изменения данных обновляются список отображаемых задач и счётчик.

### Проверка корректности ввода

Перед созданием задачи проверяется, что её название не пустое.

При отсутствии названия выводится QMessageBox с предупреждением.

Программа продолжает работать после закрытия предупреждения.
